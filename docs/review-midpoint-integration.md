# Midpoint Integration Review — "Does It Operate as One?"

**Status: working charter for the pause between PR #7 and Prompt 07 (v3.1, locked).**
**Rule:** this review produces findings, measurements, and assignments. It writes
no feature code and no spec text. Its outputs feed the v0.4 outline and the
Prompt 07 upgrade pass.

Six prompts are merged (P1–P6), each reviewed per-prompt. No review has ever
asked the whole-system question. This is that review. The failure mode it hunts:
every suite green, and the show unable to go on.

---

## [RI-0] Prerequisite — vocabulary gate

Before any other item: verify `VOCABULARY.md` sharply separates **Package**
(a static disk artifact) from **Show** (the runtime state machine), along with
**engine** vs **control plane** and **View** vs **Preview**. Every finding in
this review is phrased in those terms; if the boundary is ambiguous, halt and
patch `VOCABULARY.md` first.

**Note (from execution):** [RI-0] failed on first run — the vocabulary named
neither the runtime Show nor the two processes (engine/render node, control
plane). The patch is this gate's named output; each new entry must cite the
spec section that owns the term (e.g., render node → §5.2/§5.9, show state →
§17/§5.9.4).

## [RI-1] The dress rehearsal (the centerpiece)

One end-to-end test that plays a show. Control plane and engine together, real
processes, real package, wire-level assertions. Every existing test is scoped to
a subsystem; this is the first that fails when the parts don't compose.

### Hard thresholds (measured from the code, not guessed)

- Telemetry tick: **1000 ms** (`telemetry_interval_ms`)
- `show.stop` grace window: **2000 ms** (§5.9.5)
- "Rises above floor" means: within **2 ticks (2000 ms)** of the triggering
  command's `appliedStateVersion`
- Zero-drop is measured over the **entire scripted show**, not a window

### The package (`tests/fixtures/dress_show/`, generated by `scripts/generate-fixtures.sh`)

- House format 1920×1080/30, as declared
- `A1`: a clip with a real audio track (H.264 + AAC)
- `A2`: a 10-frame `videoLoop` with declared `periodFrames`
- `SCN_G`: a scene whose element is a `graphic` with `fields.color`
- A soundboard stab (audio asset); a real PNG fallback slate
- A manifest exercising assets, scenes, rundown, `qualityProfile`, and at least
  one `expectedDurationFrames` declaration

### The show (scripted, driven over the real WS protocol)

1. `nbe-preflight` on the package → exit 0, report fields populated
2. Control-role connect → `show.load` → `appliedStateVersion` arrives
3. `show.start` → `stateChange` RUNNING; `masterClockFrame` advancing next tick
4. Take `A1` (audio `follow`) → `busPeakDbfs.clip` rises within 2000 ms —
   wire-visible proof audio follows the take
5. Take `A2` as a 15-frame mix → `droppedFramesTotal` does not move across it
6. `soundboard.play` → `busPeakDbfs.sfx` rises; `droppedFramesTotal` stays 0
7. `audio.bus.set` on `music` → reflected on the next tick
8. `preview.set A1` → `previewItem` in telemetry
9. A timed item plays to `itemEvent: end` — the §17.3 PLAYING→DONE row, live
10. `show.stop` → ack within **2000 ms**; `stateChange` STOPPED; clock stops

### Gate assertions

- `droppedFramesTotal == 0` at show end; `audioUnderrunsTotal == 0`;
  `fallbackActive == false` throughout
- `decodeSessions >= 1`; `qualityProfile` equals the capped value, never a stub
- Gapless `appliedStateVersion` per connection
- `/status` queried mid-show and post-stop: all §10.4 fields present and sane

### Scope of this test

Happy path only. Control-plane disconnects, engine kill/OOM, and network chaos
are **out of scope here** — they belong to the AC-5 soak and the existing
reconnect suite (`tests/reconnect.rs`). This gate proves composition, not chaos.

### Artifacts on failure

Wire log (both directions), engine stderr, control-plane log, per-command
timings — uploaded as CI artifacts.

### Placement

A control-plane integration test spawning the built engine binary, on
`macos-14`, gated so zero assertions is a failure, never a skip. The 30-minute
AC-5 soak is the same harness with a longer timeline — a separate, slower gate.
A real-time gate is slow to fail by nature: **choose every timeout deliberately
and document it** (per step, not inherited defaults) — the process-spawn smoke
test cost 30 s per failure until its timeout was set on purpose.

## [RI-2] Resource composition

Do the per-prompt budgets compose on one machine?

- **Probe the reference machine at review time** (`system_profiler
  SPHardwareDataType SPDisplaysDataType` on the target hardware) and write the
  raw output to `docs/hardware-baseline.txt` — a machine-generated artifact,
  not versioned prose. Record chip, GPU cores, and unified memory there
  **before any arithmetic**. The arithmetic below uses the envelope defined in
  that file. The envelope is a measurement, not a guess.
- Sum the worst-case legal resident set: loop VRAM budgets (§12.5/§12.6), clip
  preload windows, image textures, the fallback slate, audio residency
  (48 kHz × 2 ch × 4 B × duration), telemetry structures.
- Answer: can a schema-legal, preflight-passing package exceed that machine?
  If yes, that is a preflight gap — the arithmetic lands in `docs/`, and
  "preflight enforces the resource model" becomes a v0.4-outline candidate.
- Known hole to include: the §12.6 unified-memory clamp is test-only in
  production (`recommended_working_set_mib: None` hardcoded at load).

## [RI-3] Does `/status` tell the truth?

During the dress rehearsal, trace every §10.4/§10.1 field to its producer and
verify it moves when the show moves. A field that never changes under a working
show is a stub wearing a wire. Note (from the P6 fix rounds): an assertion that
never changes under a *broken* implementation is the same failure one level
down — every field trace must show the field moving, not merely present.

## [RI-7] Platform and device adaptability audit

macOS-first is deliberate (VideoToolbox). The open-source future is served by
enumerated boundaries, not by porting now. Produce `docs/portability.md`:
every hard-coded platform assumption (VideoToolbox, Metal, macOS CI runner,
cpal's future device, ticker font handling in 07) with the boundary that
absorbs a future port. Known-good boundaries to record: the §16 command
surface (any input device), `nbe-decode` as the platform isolate,
`nbe-preflight` as a binary any pipeline can shell.

## [RI-8] The zombie-state audit (added after blind review)

A show that stops but leaves resources allocated fails the 30-minute soak.
After the dress rehearsal's `show.stop`, assert:

- `decodeSessions == 0` within the 2000 ms grace window
- Package residency (video rings, image textures, audio assets) is released —
  or explicitly held by a written policy (unload-at-stop vs
  unload-at-next-load). Decide, pin it, test it
- The audio driver keeps rendering silence by design (a fed sink is not a
  zombie) but holds no package assets
- A second `show.load` after stop accumulates nothing

## Definition of done for this review

The review is complete only when: every [RI] item has produced its named
output; every deferral-ledger row is resolved to **Verified dormant**,
**Re-deferred (new trigger)**, or **Promoted** (with its destination); the
